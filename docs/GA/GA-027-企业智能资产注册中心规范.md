# 第十四章 Registry金律

1. 所有智能资产必须注册
2. 未注册资产禁止上线
3. 所有资产必须有编码
4. 所有资产必须有Owner
5. 所有资产必须有版本
6. 所有资产必须可追溯
7. 所有资产必须可审计
8. 所有资产必须可依赖分析
9. Registry是智能资产权威源
10. Registry是ANOS治理核心
