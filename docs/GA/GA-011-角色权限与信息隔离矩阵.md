## 第5章 RBAC + ABAC 模型

```text
RBAC: Role-Based Access Control
  → 按角色分配权限

ABAC: Attribute-Based Access Control
  → 按属性(部门/数据Owner/敏感级别)动态判断
```

**ANOS采用 RBAC（基础）+ ABAC（字段级）混合模型。**
