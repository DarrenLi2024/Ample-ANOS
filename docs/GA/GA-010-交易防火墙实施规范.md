# 第一章 文档使命

定义：

Trading Firewall

交易防火墙。

------

回答：

```text
谁可以看什么

谁不可以看什么

为什么隔离

如何隔离

如何审计
```

------

本规范是：

ANOS核心治理制度。

------

# 第二章 核心原则

安芯易核心资产：

```text
客户资源

供应商资源

成交经验

交易数据
```

------

必须保护。

------

原则：

```text
客户归销售经营

供应商归采购经营

AI负责连接

组织拥有资产
```

------

# 第三章 交易防火墙定义

交易防火墙：

不是网络防火墙。

------

而是：

```text
商业信息隔离机制
```

------

目的：

```text
保护客户

保护供应商

保护组织资产
```

------

# 第四章 三域模型

ANOS划分：

Customer Domain

Supplier Domain

Trading Domain

------

# 第五章 Customer Domain

客户域。

------

包括：

```text
客户名称

联系人

电话

邮箱

决策链

采购习惯

成交历史
```

------

归属：

Sales Organization

------

# 第六章 Supplier Domain

供应商域。

------

包括：

```text
供应商名称

联系人

电话

邮箱

信源

成本价格

合作历史
```

------

归属：

Buyer Organization

------

# 第七章 Trading Domain

交易域。

------

包括：

```text
Match Result

Quote

SO

PO

成交记录
```

------

允许：

授权共享。

------

# 第八章 销售权限边界

Sales允许查看：

```text
Customer Domain

本人Inquiry

本人Quote

本人成交记录
```

------

# 第九章 销售禁止查看

Sales禁止查看：

```text
Supplier Name

Supplier Contact

Supplier Email

Buyer Note

Source Person

Source Grade

采购成本
```

------

# 第十章 采购权限边界

Buyer允许查看：

```text
Supplier Domain

本人Offer

本人资源记录

本人供应商历史
```

------

# 第十一章 采购禁止查看

Buyer禁止查看：

```text
Customer Name

Customer Contact

Customer Email

Sales Note

客户利润率

客户决策链
```

------

# 第十二章 部门主管权限

Sales Manager：

查看本部门Customer Domain。

------

Buyer Manager：

查看本部门Supplier Domain。

------

禁止跨域。

------

# 第十三章 CEO权限

CEO：

查看全部。

------

但：

所有访问必须审计。

------

# 第十四章 Match Engine权限

Match Engine：

允许同时读取：

```text
Demand Pool

Supply Pool
```

------

但：

禁止暴露原始域数据。

------

# 第十五章 Match Result输出规范

Sales看到：

```text
Match Score

资源可用

建议报价
```

------

禁止显示：

```text
Supplier Name

Supplier Contact

Source Person
```

------

# 第十六章 Buyer看到内容

Buyer看到：

```text
需求有效

需求等级

建议采购
```

------

禁止显示：

```text
Customer Name

Customer Contact

决策人
```

------

# 第十七章 Portal权限规范

Portal：

必须基于：

```text
Feishu User ID
```

动态渲染。

------

禁止：

前端隐藏。

------

必须：

后端隔离。

------

# 第十八章 Agent权限规范

Agent继承用户权限。

------

禁止：

Agent越权读取。

------

# 第十九章 数据层隔离

Demand Pool：

Customer Domain字段加密。

------

Supply Pool：

Supplier Domain字段加密。

------

# 第二十章 API隔离

任何API：

必须校验：

```text
User ID

Role

Department

Permission
```

------

# 第二十一章 审计机制

记录：

```text
Who

What

When

Why

Result
```

------

# 第二十二章 异常访问检测

监控：

```text
批量查询

异常导出

跨域访问

高频访问
```

------

自动告警。

------

# 第二十三章 飞单风险控制

系统识别：

```text
客户绕过销售

供应商绕过采购
```

------

生成：

Risk Event。

------

# 第二十四章 离职保护机制

员工离职：

立即回收：

```text
账号

权限

Agent

Portal访问
```

------

# 第二十五章 数据所有权

客户资源：

属于组织。

------

供应商资源：

属于组织。

------

员工：

拥有经营权。

------

不拥有所有权。

------

# 第二十六章 Agent所有权

Agent：

属于组织。

------

不属于个人。

------

# 第二十七章 信源保护机制

Source Person：

最高敏感等级。

------

仅：

Buyer

Buyer Manager

CEO

允许查看。

# 第三十章 交易防火墙金律

1. 客户属于组织
2. 供应商属于组织
3. 销售经营客户
4. 采购经营供应商
5. Match不暴露商业秘密
6. Portal必须隔离
7. Agent必须隔离
8. 所有访问必须审计
9. 所有资产必须保护
10. 交易防火墙高于功能便利
