# 第一章 文档使命

定义：

ANOS统一编码体系。

------

回答：

```text
资产如何命名

资产如何编号

资产如何分类

资产如何追溯

资产如何治理
```

------

本规范是：

ANOS所有智能资产的统一编码标准。

------

# 第二章 核心原则

原则一：

唯一编码。

------

原则二：

编码即身份。

------

原则三：

编码即分类。

------

原则四：

编码即治理。

------

原则五：

编码终身不变。

------

# 第三章 统一编码模型

采用：

```text

```

------

格式：

```text

-

-

-

```

------

示例：

```text

```

# 第四十章 编码金律

1. 编码即身份
2. 编码即分类
3. 编码即治理
4. 一个资产一个编码
5. 编码终身不变
6. 所有资产必须注册
7. 所有资产必须有Owner
8. 所有资产必须可追溯
9. Registry是资产权威源
10. 企业智能资产属于组织
