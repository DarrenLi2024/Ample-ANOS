# 第一章 总体定位

ANOS 仓库不再只是代码仓库，也不只是文档仓库，而是：

```text
ANOS Enterprise Architecture Repository
ANOS 企业架构资产仓库
```

它是 ANOS 的唯一官方架构事实来源。

所有正式的：

```text
战略设计
业务架构
数据架构
应用架构
技术架构
实施方案
Agent定义
Prompt资产
Workflow定义
Knowledge资产
ADR架构决策
治理规范
```

都必须进入 EAR。

未进入 EAR 的内容，不视为正式组织资产。

# 第四章 文档编号规范

## 4.1 停止使用纯数字编号

不再新增：

```text
91-
92-
93-
```

纯数字文档。

原因：

```text
容易冲突
无法识别层级
不利于AI检索
不利于长期治理
```

------

## 4.2 新编号规则

统一格式：

```text
[Layer]-[Number]-[Title].md
```

例如：

```text
EA-001-ANOS总体架构白皮书.md
SA-002-Agent-Network总体设计规范.md
DA-003-飞书多维表格总体设计方案.md
IA-004-飞书Portal实施手册.md
GA-001-文档体系与编号规范.md
ADR-001-Feishu-As-Primary-Platform.md
```

------

## 4.3 编号保留原则

已有历史文档不立即删除。

采用：

```text
Legacy ID + Canonical ID
```

例如：

```yaml
legacy_id: "43"
canonical_id: "SA-003"
title: "ANOS Portal 页面原型规范"
```

------

## 4.4 文档头部元数据

所有正式文档必须包含：

```yaml
document_id: SA-003
legacy_id: "43"
title: ANOS Portal 页面原型规范
version: V2.0.0
status: Active
owner: LTDC
layer: SA
domain: Portal
created_at: 2026-06-03
updated_at: 2026-06-03
depends_on:
  - EA-006
  - GA-005
referenced_by:
  - IA-004
```

## 5.2 ADR模板

```markdown
# ADR-001 标题

## 状态

Proposed / Accepted / Deprecated / Superseded

## 背景

说明为什么需要做这个决策。

## 决策

说明最终选择。

## 备选方案

- 方案A
- 方案B

## 决策理由

## 影响

对系统、组织、成本、风险、实施的影响。

## 后续动作

需要补充的任务。
```
