## 第1章 Trading Firewall 原则

### 1.1 核心原则

```text
Customer ↔ Sales
Supplier ↔ Buyer
```

**禁止直接建立：**

```text
Customer ↔ Buyer
Supplier ↔ Sales
```

这是电子元器件贸易行业的生存法则。

### 1.2 五大隔离原则

| 原则 | 说明 |
|------|------|
| **Customer Ownership** | 客户归 Sales 所有 |
| **Supplier Ownership** | 供应商归 Buyer 所有 |
| **Information Isolation** | 销售看不到供应商/采购看不到客户 |
| **Opportunity Shared** | 商机归 ANOS 所有，双方可见匹配度 |
| **Audit Trail Complete** | 所有跨域操作必须有审计日志 |

## 第2章 Demand Flow（需求流）

```text
Customer（客户）
    ↓
Sales（销售）
    ↓
Inquiry（询价）
    ↓
Buyer（采购）
    ↓
Supplier（供应商）
```

**约束：** Sales 输入 Inquiry → Buyer 接收需求 → Buyer 不可见 Customer 信息

---

## 第3章 Supply Flow（供应流）

```text
Supplier（供应商）
    ↓
Buyer（采购）
    ↓
Offer（报价）
    ↓
Sales（销售）
    ↓
Customer（客户）
```

**约束：** Buyer 输入 Offer → Sales 接收报价 → Sales 不可见 Supplier 信息

---

## 第4章 数据脱敏规则

### 4.1 Sales 侧隐藏

| 字段 | 脱敏方式 |
|------|---------|
| SupplierName | 显示为 SR-XXX |
| SupplierContact | 隐藏 |
| SourceChannel | 隐藏 |
| PurchaseCost | 隐藏或区间化 |

### 4.2 Buyer 侧隐藏

| 字段 | 脱敏方式 |
|------|---------|
| CustomerName | 显示为客户 ID |
| CustomerContact | 隐藏 |
| SalesNote | 隐藏 |
| CustomerStrategy | 隐藏 |

### 4.3 共享可见

| 信息 | 双方可见 |
|------|---------|
| MPN / Brand / Quantity | ✅ |
| Match Score | ✅ |
| Suggested Price | ✅ |
| Lead Time | ✅ |
| Opportunity Status | ✅ |

---

## 第5章 Agent 防火墙

### 5.1 Sales Agent 禁止

- 访问 SupplierContact
- 访问 PurchaseCost
- 直接联系供应商
- 生成采购建议

### 5.2 Buyer Agent 禁止

- 访问 CustomerContact
- 访问 SalesNote
- 直接联系客户
- 生成销售报价

---

## 第6章 Workflow 约束

```text
WF-001 Inquiry Intake:  Sales → Buyer（单向）
WF-002 Supply Intake:   Buyer → Sales（单向）
WF-003 Opportunity Match: 双向共享（脱敏）
WF-004 AR Risk:         风控可见全量（含客户）
```
