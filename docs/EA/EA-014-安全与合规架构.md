## 安全分层

| 层 | 机制 | 实现 |
|----|------|------|
| 认证 | JWT (Phase1) → 飞书SSO (Phase2) | auth middleware |
| 授权 | RBAC + ABAC | permission middleware |
| 数据 | Trading Firewall | 字段级脱敏 |
| 审计 | 全量操作日志 | audit-log middleware |
| 传输 | HTTPS (生产) | — |
| 防护 | CSRF + RateLimit + CSP | security middleware |

## 合规对齐

- 数据分类: Customer/Supplier/Finance/HR
- 最小权限: 每个角色仅可见必须数据
- 审计追溯: 所有操作可追溯至 Source + Actor
