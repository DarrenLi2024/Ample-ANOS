## 核心流程链

```text
Customer → Inquiry → Opportunity → Offer → SO → AR
Supplier → Supply Resource → Opportunity → Offer → PO → AP
```

## 流程归属

| 流程 | Domain | Owner |
|------|--------|-------|
| RFQ → Inquiry | Customer Domain | Sales |
| Supply → Resource | Supplier Domain | Buyer |
| Match → Opportunity | Shared Domain | ANOS |
| Opportunity → Offer | Shared Domain | Sales+Buyer |
| SO → AR | Finance Domain | Finance |
