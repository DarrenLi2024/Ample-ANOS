# ADR-001 飞书作为Phase 1主要平台

## 状态
Accepted (2026-06)

## 背景
ANOS需要选择Phase 1的基础设施平台。候选方案: 自建Web平台 vs 飞书生态。

## 决策
Phase 1 采用飞书生态作为主要平台（多维表格+妙搭+知识库+审批流），不优先建设重型自研中台。

## 备选方案
- 方案A: 全部自建 (Next.js+PostgreSQL)
- 方案B: 飞书原生优先

## 决策理由
飞书已具备多维表格、审批流、知识库等基础能力，Phase 1 重点验证业务闭环，避免基础设施过度投资。

## 影响
- Portal 前端: 飞书妙搭+自研 Next.js 混合
- 数据存储: 飞书多维表格+SQLite
- 降低初始部署成本
