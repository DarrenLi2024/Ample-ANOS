## 技术栈

- Portal: Next.js 15 + React 19 + Tailwind CSS 4
- API: Hono 4 + better-sqlite3 + Drizzle ORM
- Auth: JWT (Phase1) → 飞书SSO (Phase2)
- MCP: @modelcontextprotocol/sdk
- DevOps: pnpm + turborepo + Docker + GitHub Actions

## 部署架构

```text
Client → Portal (Next.js) → API (Hono) → SQLite/飞书多维表格
```

## 性能指标

- 页面首屏 < 3s
- API 响应 < 500ms
- Phase2 PostgreSQL 支持 250 并发
