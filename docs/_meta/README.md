# docs/_meta — 文档元信息

本目录是 ANOS EAR 的文档治理中枢。

| 文件 | 用途 |
|------|------|
| `document-registry.yaml` | 48份正式文档的完整注册表 |
| `document-map.yaml` | 文档依赖关系图 |
| `legacy-mapping.yaml` | 旧编号→新编号映射表 |
| `document-inventory.md` | 文档清单汇总 |

**AI/Codex 查找文档:** 先查 registry → 再查 map 确认依赖 → 用 legacy-mapping 对照旧编号
