## 1. 使用说明

本文件定义P0必须通过的端到端验收样例。

每个样例应包含：

- 输入Source。
- 预期结构化结果。
- 触发Workflow。
- Agent输出。
- Portal展示。
- 权限与审计检查。
- 通过标准。

## 3. E2E-001 客户RFQ进入

## 输入

| 项目 | 内容 |
| --- | --- |
| SourceType | Email / 截图 / Excel / PDF |
| SourceURL | 待填写 |
| SourceOwner | 销售人员 |
| 样例文件 | 待填写 |

## 预期结构化字段

- Customer
- Contact
- Brand
- MPN
- Quantity
- TargetPrice
- RequiredDate
- SourceType
- EventTime
- CapturedAt
- ConfidenceScore

## 预期结果

- 生成Inquiry记录。
- 低置信度字段进入人工确认。
- Sales Agent生成RFQ摘要。
- 销售工作台可看到待处理RFQ。
- Source Card可显示来源和可信度。

## 通过标准

- 关键字段识别准确率达到验收要求。
- Source字段完整。
- 审计日志存在。

## 4. E2E-002 供应商报价单进入

## 输入

| 项目 | 内容 |
| --- | --- |
| SourceType | Excel / Email / 截图 |
| SourceURL | 待填写 |
| SourceOwner | 采购人员 |
| 样例文件 | 待填写 |

## 预期结构化字段

- Supplier
- Brand
- MPN
- StockQty
- Price
- LeadTime
- MOQ
- DateCode
- SourceType
- ConfidenceScore

## 预期结果

- 生成Supply Resource记录。
- Procurement Agent生成资源评估。
- 采购工作台展示Resource Intelligence Card。
- 高风险或低置信度记录进入待确认。

## 通过标准

- MPN、价格、库存、交期可被正确提取。
- Source Card完整。
- 采购价字段不对未授权角色开放。

## 5. E2E-003 供需匹配生成Opportunity

## 输入

- 一条已确认Inquiry。
- 一条或多条Supply Resource。

## 预期匹配维度

- 型号
- 库存
- 价格
- 交期
- 风险
- 授权

## 预期结果

- 生成Opportunity。
- 生成MatchScore。
- 展示匹配依据。
- Sales Agent生成报价建议草案。
- 采购可查看相关供应资源。

## 通过标准

- Opportunity能关联Inquiry和Supply Resource。
- MatchScore有可解释依据。
- 不自动发送正式报价。

## 6. E2E-004 AR逾期风险预警

## 输入

- 一条客户AR记录。
- DueDate和OutstandingAmount。

## 预期结果

- 计算OverdueDays。
- 生成RiskLevel。
- Credit Agent生成催收建议。
- 风控工作台展示AR Risk Radar。
- 销售只能看到自己客户相关风险。

## 通过标准

- 风险等级正确。
- 风险建议有来源和依据。
- 不自动冻结信用或停单。

## 7. E2E-005 知识文档引用

## 输入

- 一份销售/采购/风控SOP。
- 一条与SOP相关的业务问题。

## 预期结果

- 知识记录有Owner、SourceURL、UpdatedAt。
- Agent回答引用该知识。
- 输出包含来源、时间、可信度。

## 通过标准

- Agent不能无来源回答关键业务建议。
- 未授权知识不应被返回。

## 8. E2E-006 权限与Source Card验证

## 测试账号

| 角色 | 账号 | 状态 |
| --- | --- | --- |
| 销售 | 待填写 | 待准备 |
| 采购 | 待填写 | 待准备 |
| 财务/风控 | 待填写 | 待准备 |
| CEO | 待填写 | 待准备 |
| Admin | 待填写 | 待准备 |

## 测试项

- 销售不能查看未授权采购价。
- 采购不能查看未授权客户敏感信息。
- 财务可查看AR风险。
- Agent不能调用未授权Tool。
- SourceURL按权限展示。
- 导出行为进入审计。

## 通过标准

- 无高危越权。
- 审计日志完整。
- Source Card显示符合权限矩阵。
