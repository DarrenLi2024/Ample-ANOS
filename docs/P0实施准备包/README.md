## 1. 准备包目标

本准备包用于在正式开发、飞书建表、Workflow搭建、ERP接入前，补齐真实实施所需的关键输入。

文档体系已经足够进入P0，但还需要以下真实Source和业务确认：

- P0关键决策。
- 飞书现有资产。
- ERP样例数据。
- 权限矩阵。
- 端到端验收样例。

```text
P0决策确认
↓
飞书资源盘点
↓

↓
端到端验收样例确认
↓

```

## 4. 完成标准

准备包完成后应满足：

- 每个关键决策都有确认结果或待确认Owner。
- 飞书资源清单包含真实URL或位置说明。
- ERP样例数据覆盖P0对象和异常样例。
- 权限矩阵覆盖角色、字段、Source、Agent Tool。
- 验收样例可被用于测试Data Hub、Workflow、Portal和Agent。

## 5. 注意事项

- 不要在本仓库提交真实敏感数据。
- ERP样例建议脱敏后放入受控目录或飞书受控空间。
- 本准备包可以记录字段、样例结构和文件位置，但不应直接包含客户价格、毛利、合同、付款等敏感原文。
