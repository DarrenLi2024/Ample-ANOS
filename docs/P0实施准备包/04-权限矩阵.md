## 1. 权限标记

| 标记 | 含义 |
| --- | --- |
| R | 可读 |
| W | 可写 |
| A | 可审批/确认 |
| X | 不可见 |
| Masked | 脱敏可见 |
| Own | 仅本人/本部门负责范围 |
| All | 全部范围 |
