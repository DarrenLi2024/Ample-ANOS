# 第1章 Portal设计哲学

## 1.1 ERP时代

ERP时代员工工作模式：

```text
找数据
↓
看报表
↓
人工分析
↓
人工决策
↓
人工执行
```

ERP核心是：

```text
人找数据
```

系统只是功能菜单和记录工具。

## 1.2 AI Native时代

AI Native时代员工工作模式：

```text
目标
↓
AI理解
↓
AI分析
↓
AI建议
↓
AI执行
↓
人工确认
```

核心变成：

```text
数据找人
```

ANOS Portal不是菜单系统，而是AI工作伙伴。

## 1.3 Portal定位

ANOS Portal定位为：

> 企业AI操作系统桌面（Enterprise AI Workspace）。

员工不会天天打开ERP、多维表格、数据库。

员工每天打开的是Portal。

Portal才是真正意义上的AI Native Operating System入口。

# 第2章 Portal总体布局

ANOS Portal采用三纵列架构。

这是当前OpenAI、Anthropic、Cursor、Devin、Manus、飞书Aily等AI原生产品共同演进出的主流结构。

```text
┌───────────────────────────────────────────────┐
│ Left          │ Center              │ Right   │
├───────────────┼─────────────────────┼─────────┤
│ 身份与导航区  │ AI会话 + 工作区      │ 输出区  │
└───────────────┴─────────────────────┴─────────┘
```

三列定位：

| 区域 | 英文定位 | 核心作用 |
| --- | --- | --- |
| 左侧 | Identity + Navigation | 身份、导航、领域入口 |
| 中间 | Conversation + Workspace | AI会话、任务工作、文件入口 |
| 右侧 | Task Output + Agent Panel | 结果输出、建议、风险、Agent状态 |

# 第4章 中间工作区

中间区是整个Portal的灵魂。

建议占屏幕空间：

```text
55%
```

中间区同时承担：

- AI搜索
- AI会话
- 任务处理
- 文件上传
- 数据查看
- 表单录入

## 4.1 顶部AI搜索栏

顶部提供统一AI搜索栏：

```text
你想完成什么工作？
```

支持自然语言目标：

- 找客户
- 分析库存
- 整理询价
- 追踪回款
- 找国产替代
- 生成报价
- 分析供应商风险

## 4.2 AI会话区

AI会话区类似ChatGPT、Claude、Manus体验。

示例：

销售输入：

```text
帮我分析今天收到的RFQ
```

采购输入：

```text
帮我寻找替代供应商
```

风控输入：

```text
查看超过90天未回款客户
```

CEO输入：

```text
给我今天经营风险摘要
```

## 4.3 任务工作区

AI会话结果可以直接转为任务卡片。

任务卡片包括：

- 任务标题
- 关联对象
- 负责人
- 截止时间
- AI建议
- 当前状态
- 人工确认按钮

## 4.4 底部统一输入入口

底部提供统一输入入口。

支持：

- 文本
- Excel
- PDF
- 图片
- 邮件
- 截图
- 拖拽上传

这是ANOS最重要的信息入口。

## 第11章 销售-采购信息隔离（2026-06 补充）

### 11.1 核心原则

```
销售不能直通供应商
采购不能直通客户
```

这是电子元器件贸易行业的生存法则。

### 11.2 信息流向

```
客户 → 销售 → Inquiry → Opportunity → 采购 → 供应商
                        ↓
               Opportunity Card
          (双方都可见匹配度/型号/数量)

但:
  销售的Inquiry → 供应商名称永远脱敏
  采购的Offer   → 客户名称永远脱敏
```

### 11.3 角色视图隔离

| 信息 | 销售可见 | 采购可见 | 风控可见 | CEO可见 |
|------|---------|---------|---------|--------|
| 客户名称 | ✅ 明文 | ❌ 脱敏为ID | ⚠️ 按需 | ⚠️ 聚合 |
| 供应商名称 | ❌ 脱敏为SR-XXX | ✅ 明文 | ❌ 隐藏 | ⚠️ 聚合 |
| 采购价 | ❌ 隐藏 | ✅ 明文 | ❌ 隐藏 | ❌ 隐藏 |
| 销售目标价 | ✅ 明文 | ❌ 隐藏 | ❌ 隐藏 | ⚠️ 聚合 |
| 匹配度 | ✅ 可见 | ✅ 可见 | ✅ 可见 | ✅ 可见 |

## 10.5 本文档结论

Portal不是ANOS的展示层。

Portal是ANOS的工作入口。

它将数据、知识、Agent、Workflow和人统一到一个AI Native Workspace中。

Portal是否好用，将直接决定ANOS能否替代传统ERP菜单，成为AMPLE未来统一数字工作台。
