# 26-开发任务拆解与里程碑计划 V1.0

**项目名称：** Ample AI Native OS（ANOS）  
**文档定位：** 开发任务拆解 / 里程碑计划 / Sprint基线  
**上游文档：** [01-ANOS项目范围与MVP定义 V1.0.md](01-ANOS项目范围与MVP定义%20V1.0.md)  
**版本：** V1.0  
**状态：** P0开发前基线

---

# 第1章 里程碑总览

P0建议分6个Sprint，每个Sprint 1-2周。

| 里程碑 | 目标 |
| --- | --- |
| M0 | 项目结构、权限、环境、样例数据准备 |
| M1 | Data Hub P0表可用 |
| M2 | ERP导入与同步基础链路可用 |
| M3 | AI Inbox + Intake Workflow可用 |
| M4 | 销售/采购/风控Portal可用 |
| M5 | Agent基础工具与审计可用 |
| M6 | MVP验收与试运行 |

# 第2章 Epic拆解

| Epic | 名称 | 说明 |
| --- | --- | --- |
| EPIC-01 | Data Hub | 飞书多维表格与未来SQL模型 |
| EPIC-02 | ERP Integration | ERP数据导入、同步、映射 |
| EPIC-03 | AI Inbox | 统一智能入口 |
| EPIC-04 | Workflow | 资产登记、询价、供应、匹配、AR风险 |
| EPIC-05 | Portal | 销售、采购、风控工作台 |
| EPIC-06 | Agent Tools | Sales/Procurement/Credit Agent工具 |
| EPIC-07 | Permission & Audit | 权限、审计、Source Card |
| EPIC-08 | Testing & Acceptance | 测试、验收、试运行 |

# 第3章 Sprint 0

目标：工程准备。

任务：

- 建立GitHub目录结构。
- 建立文档索引。
- 确认飞书空间、应用、权限。
- 准备ERP样例导出数据。
- 确认P0字段。
- 建立测试数据集。

输出：

- 仓库结构。
- 环境说明。
- 样例数据。
- P0字段确认表。

# 第4章 Sprint 1

目标：Data Hub P0表可用。

任务：

- 建立Customer Base。
- 建立Supplier Base。
- 建立Product Base。
- 建立Inquiry Base。
- 建立Supply Resource Base。
- 建立Opportunity Base。
- 建立AR Risk Base。
- 建立Source字段和Data Health Score。

# 第5章 Sprint 2

目标：ERP导入和同步基础链路。

任务：

- 建立ERP Raw Zone。
- 实现Customer导入。
- 实现Supplier导入。
- 实现Product导入。
- 实现SO/AR样例导入。
- 生成同步日志。
- 建立冲突队列。

# 第6章 Sprint 3

目标：AI Inbox与P0 Workflow。

任务：

- 实现AI Inbox基础入口。
- 实现WF-000 Asset Registration。
- 实现WF-001 Inquiry Intake。
- 实现WF-002 Supply Intake。
- 实现WF-003 Opportunity Matching规则版。
- 实现WF-004 AR Risk规则版。

# 第7章 Sprint 4

目标：Portal工作台。

任务：

- 销售工作台。
- 采购工作台。
- 风控工作台。
- Source Card组件。
- Customer Intelligence Card。
- Resource Intelligence Card。
- AR Risk Radar。

# 第8章 Sprint 5

目标：Agent工具与审计。

任务：

- CustomerQueryTool。
- InquiryCreateTool。
- SupplyResourceQueryTool。
- OpportunityMatchTool。
- ARRiskQueryTool。
- KnowledgeSearchTool。
- Agent Audit Log。
- Human Approval基础流程。

# 第9章 Sprint 6

目标：验收与试运行。

任务：

- 端到端测试。
- 权限测试。
- 数据质量测试。
- Agent输出测试。
- Workflow失败处理测试。
- 业务试运行复盘。

# 第10章 依赖关系

```text
Data Hub
↓
ERP导入
↓
Workflow
↓
Agent Tool
↓
Portal
↓
验收
```

Portal可与Workflow并行开发，但不能脱离Data Hub字段标准。

# 第11章 交付定义

每个任务必须包含：

- 输入文档
- 输出文件或配置
- Owner
- 验收标准
- 测试方式
- 风险说明
