## 1. 全局UI约束

| 约束 | 开发含义 |
| --- | --- |
| 浅色侧边栏 | 销售、采购、风控、知识、Agent、系统管理使用同一导航背景与选中态 |
| 底部指令栏 | 每个工作台页面都保留贴近底部的人机对话入口 |
| 三纵列工作台 | 左导航、中央主任务区、右侧上下文卡片区 |
| Source First | 右侧卡片必须能追溯来源、可信度、采集时间和审计状态 |
| Human-in-the-loop | 关键动作必须有人工确认、退回或审批入口 |
| 权限前置 | 页面渲染前先计算角色、对象、字段和动作权限 |

## 2. 页面级说明

| 图 | 页面 | 核心组件 | 关键开发注意事项 |
| --- | --- | --- | --- |
| 01 | AI Inbox首页 | KPI卡、动态流、Agent建议、Source Card、底部指令栏 | 首页也要按当前角色脱敏，不能作为“全量混合视图” |
| 02 | 销售工作台 | 我的RFQ、匹配供应摘要、客户智能卡、Sales Agent建议 | 供应侧只能出现资源ID、匹配度、采购Owner和脱敏证据 |
| 03 | 采购工作台 | 供应资源池、可匹配需求、资源智能卡、采购确认 | 客户侧只能出现客户ID、销售Owner和需求摘要 |
| 04 | 风控工作台 | AR风险雷达、客户信用卡、催收建议、审计轨迹 | 风控能看客户信用和AR，但不应暴露采购成本 |
| 05 | Opportunity销售视图 | 需求卡片、供需匹配、报价建议、销售审批 | 不允许展示供应商明文和采购价 |
| 06 | Opportunity采购视图 | 需求摘要、供应资源详情、供应商对比、采购确认 | 不允许展示客户明文和客户信用 |
| 07 | RFQ解析 | 原始RFQ预览、字段解析、校验问题、创建Inquiry | 字段置信度低时必须进入人工校验 |
| 08 | 供应资源解析 | 报价单预览、OCR/表格识别、资源草稿、写入资源池 | 同一供应商重复记录和DateCode缺失要提示 |
| 09 | 报价确认 | AI报价建议、报价草案、毛利护栏、销售确认 | 成本依据只能以脱敏区间或资源ID体现 |
| 10 | AR处置 | 账龄分布、发票明细、Credit Agent建议、处置动作 | 每个处置动作都要写审计日志 |
| 11 | 客户360 | 客户基础画像、动态时间线、商机、AR摘要、下一步动作 | 销售可见客户经营信息，但不得显示供应商名单 |
| 12 | 工作流运营中心 | Workflow Runs、错误队列、重试、Source First检查 | 运维视角默认显示对象ID和脱敏摘要 |
| 13 | Agent中心 | Agent卡、任务列表、工具权限、审计日志 | Agent工具权限要按角色和环境分级启停 |
| 14 | 知识问答 | 分类入口、回答、引用来源、生命周期、评审状态 | 引用来源必须显示权限状态，无权限不得泄露正文 |
| 15 | 国产替代推荐 | 替代料列表、参数匹配、风险原因、样品申请 | 采购可见供应商和产品来源，客户需求保持脱敏 |
| 16 | CEO经营摘要 | 经营KPI、机会地图、AR趋势、OIQ指数、受控钻取 | 默认聚合，明细钻取需要权限申请 |

## 3. 字段级权限实现建议

| 字段类别 | 销售视图 | 采购视图 | 管理/运营视图 |
| --- | --- | --- | --- |
| CustomerName | 明文 | 脱敏为客户ID | 聚合默认脱敏，授权后明文 |
| CustomerCredit | 按销售权限显示摘要 | 隐藏 | 风控/CEO按权限显示 |
| SupplierName | 脱敏为供应资源ID | 明文 | 聚合默认脱敏，授权后明文 |
| ProcurementCost | 隐藏或区间化 | 明文 | 默认隐藏，授权后可见 |
| SourceURL | 客户来源可见 | 供应来源可见 | 按对象权限控制 |
| AgentReasoning | 可见与本角色相关摘要 | 可见与本角色相关摘要 | 可见脱敏摘要和审计链 |
